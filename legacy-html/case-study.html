01

โจทย์ที่ลูกค้าต้องการแก้

โครงการโซลาร์ฟาร์ม 50MW ในจังหวัดลพบุรี เป็นหนึ่งในโครงการขายไฟให้การไฟฟ้าฝ่ายผลิต ที่กำหนดเงื่อนไขเรื่องการรายงานข้อมูลอย่างเคร่งครัด ทุก Inverter Station ต้องส่งข้อมูล kWh, kVAR, PF และคุณภาพไฟฟ้ากลับไปยังระบบกลางของการไฟฟ้าแบบเรียลไทม์ ตลอด 24/7 หากผิดพลาดเพียงจุดเดียว อาจถูกหักรายได้ทั้งเดือน

ก่อนหน้านี้ทีมงานของลูกค้าต้องเดินเก็บค่ามิเตอร์ทุก Station ด้วยมือ คำนวณ TOU ในไฟล์ Excel และเตรียมรายงานส่งการไฟฟ้าทุกเดือน ใช้เวลามากกว่า 5 วันทำการ และมีโอกาสผิดพลาดจากการป้อนข้อมูลด้วยมือ

02

วิธีของ Advanced Grid

Advanced Grid เข้าไปสำรวจหน้างาน ออกแบบสถาปัตยกรรมระบบใหม่ทั้งหมดให้ผ่านมาตรฐาน Tariff Metering ของการไฟฟ้า โดยใช้อุปกรณ์ระดับ Class 0.2S เป็นหลัก พร้อมระบบสื่อสารที่ออกแบบสำหรับสภาพแวดล้อมกลางแจ้งของโซลาร์ฟาร์ม

  • ติดตั้ง CEWE Prometer 100 (Class 0.2S) ที่จุดเชื่อมต่อ Grid และ Inverter Station หลัก
  • วาง CEWE ProQ 100 Power Quality Analyzer ที่จุด Point of Common Coupling เพื่อตรวจคุณภาพไฟฟ้าตาม IEC 61000-4-30 Class A
  • ออกแบบและประกอบ Meter Box + Communication Box แบบ Outdoor IP54 พร้อม Lightning Protection
  • สร้างระบบสื่อสาร RS-485 → Fiber Backbone → 4G/Cellular Failover ไปยัง SCADA ของลูกค้าและการไฟฟ้า
  • ทำ Commissioning และ Witness Test ร่วมกับวิศวกรของการไฟฟ้า — ผ่านในรอบเดียว
ทีม Advanced Grid เข้าใจดีว่าการไฟฟ้าต้องการอะไร และระบบที่ส่งมอบทำงานได้ตามที่เราขอ ตั้งแต่วันที่เปิดสวิตช์เลย — ไม่ต้องมาแก้ทีหลัง

03

ผลลัพธ์

หลังจากระบบเปิดใช้งาน ทีมของลูกค้าไม่ต้องเดินจดมิเตอร์ในแต่ละเดือนอีกต่อไป ข้อมูลทุกจุดถูกส่งเข้า SCADA และการไฟฟ้าโดยอัตโนมัติ การทำรายงานรายเดือนเหลือเพียงครึ่งวัน และข้อมูลที่ส่งให้การไฟฟ้าผ่านการตรวจสอบทุกครั้ง

Advanced Grid ยังให้บริการ Calibration ประจำปีและ Support 24/7 เพื่อให้ระบบทำงานต่อเนื่องตลอดอายุสัญญา PPA 25 ปี
