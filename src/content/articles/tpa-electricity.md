## TPA (ไฟฟ้า) คืออะไร

TPA (Third Party Access หรือสิทธิ์การใช้และเชื่อมต่อระบบโครงข่ายไฟฟ้าให้แก่บุคคลที่สาม)
ในตลาดไฟฟ้าไทย คือกลไกที่เปิดให้ผู้ผลิตไฟฟ้าพลังงานหมุนเวียนภาคเอกชน "เดินสาย"
ไฟฟ้าผ่านระบบส่งและระบบจำหน่ายของการไฟฟ้า ไปยังผู้ซื้อไฟฟ้าเอกชนอีกรายหนึ่งได้
โดยตรง — โดยไม่ต้องขายไฟฟ้าเข้าระบบของการไฟฟ้าก่อนแล้วค่อยซื้อคืน กลไกนี้คือ
รากฐานที่ทำให้สัญญาซื้อขายไฟฟ้าโดยตรง หรือ Direct PPA (Direct Power Purchase
Agreement) ระหว่างเอกชนกับเอกชน เกิดขึ้นได้จริงบนโครงข่ายไฟฟ้าที่มีอยู่เดิม

จุดเริ่มต้นเชิงนโยบายคือมติคณะกรรมการนโยบายพลังงานแห่งชาติ (กพช.) เมื่อวันที่
25 มิถุนายน 2567 ที่เห็นชอบแนวทางโครงการนำร่อง Direct PPA ขนาด 2,000 เมกะวัตต์
(MW) โดยมีกลุ่มเป้าหมายหลักคือผู้ใช้ไฟฟ้าที่ต้องการพลังงานสะอาดปริมาณมาก เช่น
ดาต้าเซนเตอร์และนักลงทุนต่างชาติ การจะซื้อขายไฟฟ้าในรูปแบบนี้ได้ ผู้ซื้อและ
ผู้ขายต้องขอใช้บริการ TPA จากหน่วยงานที่ดูแลระบบโครงข่ายไฟฟ้า ภายใต้การกำกับ
ของคณะกรรมการกำกับกิจการพลังงาน หรือ กกพ. (Energy Regulatory Commission: ERC)

## TPA ไฟฟ้า ≠ TPA Code ก๊าซธรรมชาติ — คนละเรื่องกัน

ผู้ค้นหาข้อมูล "TPA" ในไทยมักสับสนกับ TPA Code ฉบับเก่าของ กกพ. ซึ่งเป็นคนละ
เรื่องกันโดยสิ้นเชิงกับ TPA ไฟฟ้าที่กล่าวถึงข้างต้น:

- **TPA Code (ก๊าซธรรมชาติ)** — ระเบียบที่ กกพ. เผยแพร่ไว้ตั้งแต่ปี 2558
  ครอบคลุมการเปิดให้บุคคลที่สามใช้ระบบท่อส่งก๊าซธรรมชาติและสถานี LNG ที่ ปตท.
  เป็นผู้ดำเนินการ เพื่อลดการผูกขาดและเปิดทางให้ผู้ค้าก๊าซรายใหม่แข่งขันได้
  โดย TPA Code บนบก (Onshore) ของ ปตท. ได้รับอนุมัติเมื่อ 30 มีนาคม 2558 ส่วน
  TPA Code สถานี LNG มีทั้งฉบับแรกวันที่ 30 มีนาคม 2558 ฉบับที่ 2 วันที่ 21
  ตุลาคม 2558 และปรับปรุงล่าสุดเป็นฉบับที่ 3 เมื่อ 31 มีนาคม 2563 — เรื่องนี้
  **ไม่เกี่ยวข้องกับไฟฟ้าแต่อย่างใด**
- **TPA (ไฟฟ้า)** — กลไกใหม่ที่เพิ่งเข้าสู่กระบวนการกำหนดอัตราค่าบริการในปี
  2568 เพื่อรองรับโครงการนำร่อง Direct PPA โดยเฉพาะ ใช้ชื่อย่อเดียวกันเพราะ
  หลักการพื้นฐาน "เปิดให้บุคคลที่สามใช้โครงข่ายที่มีอยู่" เหมือนกัน แต่ใช้กับ
  โครงสร้างพื้นฐานคนละประเภท (สายส่ง/สายจำหน่ายไฟฟ้า แทนที่จะเป็นท่อส่งก๊าซ)

หากค้นหาแล้วเจอหน้า TPA Code ของ กกพ. (erc.or.th/th/tpa) แล้วเนื้อหาพูดถึง
ก๊าซธรรมชาติหรือ LNG แสดงว่ากำลังอ่านเรื่องคนละเรื่องกับ TPA ไฟฟ้าที่บทความนี้
กล่าวถึง

## อัตราค่าบริการ TPA: อยู่ระหว่างกำหนดอัตรา

กกพ. เปิดรับฟังความเห็นร่าง "อัตราค่าบริการการใช้และเชื่อมต่อระบบโครงข่ายไฟฟ้า
ให้แก่บุคคลที่สาม (TPA) สำหรับโครงการนำร่องซื้อขายไฟฟ้าจากพลังงานหมุนเวียนใน
รูปแบบ Direct PPA" จนถึงวันที่ 10 พฤศจิกายน 2568 โดยโครงสร้างอัตราค่าบริการ
แบ่งออกเป็น 5 องค์ประกอบหลัก:

1. **ค่าบริการระบบส่งและระบบจำหน่ายไฟฟ้า (Wheeling Charge)** — ค่าใช้สายส่ง/
   สายจำหน่ายเพื่อลำเลียงไฟฟ้าจากผู้ขายไปยังผู้ซื้อ
2. **ค่าบริการเชื่อมต่อระบบโครงข่ายไฟฟ้า (Connection Charge)**
3. **ค่าบริการเสริมความมั่นคงระบบไฟฟ้า (System Security Charge)**
4. **ค่าบริการหรือค่าปรับในการปรับสมดุลปริมาณไฟฟ้า (Imbalance Charge)**
5. **ค่าใช้จ่ายเชิงนโยบาย (Policy Expenses)**

## ทำไมเรื่องนี้ถึงสำคัญกับผู้ที่ต้องวัดและคิดค่าไฟ

เมื่อไฟฟ้าไหลผ่านระบบโครงข่ายภายใต้ข้อตกลง TPA ระหว่างคู่สัญญา Direct PPA
การวัดปริมาณไฟฟ้าที่แม่นยำและระบบคิดค่าบริการที่สอดคล้องกับโครงสร้างอัตรา
ทั้ง 5 องค์ประกอบข้างต้น จะเป็นเงื่อนไขพื้นฐานที่ขาดไม่ได้สำหรับทุกฝ่ายที่
เกี่ยวข้องในห่วงโซ่การซื้อขายไฟฟ้ารูปแบบใหม่นี้
